# Tendrils CRM 4.9.18 (frontend only)
## Tickets page
- New filters (employees), next to All / My tickets / Unrouted / Overdue (all kept): **Created by me**, **Assigned to me**, **For my team**. Each shows a count and filters the list.
- Summary cards (Open, Waiting for review, Needs info, Overdue, Unassigned): click to narrow the list.
- Sort (newest, oldest, recently updated, due soonest, highest priority; default unchanged), Table / Card layout switch (remembered), and "Show 25 more" paging for long lists.
- Table: priority colour bar, ticket key chip, due date highlighted (late in red with "3d late", today/tomorrow in amber). All existing columns and filters unchanged.
## Broadcast
- Redesigned: 3-step layout (Who / What / How), audience cards, team tiles, people picker with avatars, select all shown, selected chips, character counters, email + urgent toggles, live preview, "Send to N" button.
No API or database changes.
