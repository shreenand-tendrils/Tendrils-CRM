# Tendrils CRM 4.9.14
## Create forms
- "Attach files" now sits right after the Description field (ticket and task create forms), instead of at the bottom.
## Ticket & task windows (frontend only)
- Title block + meta strip (raised/created by, created, client/team, last update).
- Description in its own card with an "Attachments (n)" shortcut that jumps to the Files tab.
- Pill-style tabs that stay pinned while you scroll; comment box stays pinned at the bottom of the Comments tab.
- Comments: avatar + name + time header, your own comments tinted, internal notes shown in amber with an "Internal note" tag (ticket and task).
No schema changes / migrations.
